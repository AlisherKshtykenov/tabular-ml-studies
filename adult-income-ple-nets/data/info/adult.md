# Adult Census Income

**Источник:** выборка из переписи населения США 1994 года, UCI Machine Learning Repository, скачано с OpenML (`adult`, версия 2). Лицензия CC BY 4.0.

**Строка:** один взрослый человек. **Цель:** годовой доход выше 50 тысяч долларов (`class`).

| Столбец | Тип | Смысл |
|---|---|---|
| `age` | число | Возраст, потолок анкеты 90 |
| `workclass` | категория | Тип работодателя (частный, государственный и так далее), есть пропуски |
| `fnlwgt` | число | Вес человека в переписи: сколько людей он представляет. Не свойство человека |
| `education` | категория | Уровень образования |
| `education-num` | число | Тот же уровень образования кодом от 1 до 16 |
| `marital-status` | категория | Семейное положение |
| `occupation` | категория | Профессия, есть пропуски |
| `relationship` | категория | Роль в семье (муж, жена, ребёнок и другие) |
| `race` | категория | Раса в терминах переписи |
| `sex` | категория | Пол |
| `capital-gain` | число | Доход от капитала, потолок анкеты 99999 |
| `capital-loss` | число | Убыток от капитала |
| `hours-per-week` | число | Часов работы в неделю, потолок анкеты 99 |
| `native-country` | категория | Страна рождения, есть пропуски |
| `class` | цель | `<=50K` или `>50K` |

**Ограничение.** Данным больше 30 лет: порог 50 тысяч и связь дохода с полом и расой отражают США 1994 года, а не сегодняшний день. Модель подходит для учебного сравнения, а не для решений о людях.
